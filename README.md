# Motivatorator

A motivational and brutally demotivational VST3 studio companion.

## Concept

Motivatorator is a deliberately fun VST3 audio effect that leaves the incoming audio unchanged while displaying humorous studio comments at configurable intervals.

### Planned modes

- **Motivator** — relentlessly positive comments
- **Demotivator** — deliberately harsh but playful roast-style comments
- **Mixed** — alternates between both personalities

### Planned features

- German / English
- Configurable time interval
- Large comment display
- NEXT button for an immediate new comment
- MUTE ME switch
- Optional spoken comments in a later stage
- Shuffle-bag selection so comments do not repeat until the current pool has been exhausted
- State recall inside the host project
- Stereo audio pass-through without altering the music

## Goal

Making music should be fun.

## Status

Early development / prototype.
